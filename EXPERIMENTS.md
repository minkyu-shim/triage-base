# Experiments

One row per experiment. Iteration rule: observed failure → hypothesis → **one** prompt or config change → re-test → keep or revert.

Provider for every row: Google Gemini through its OpenAI-compatible endpoint (Chat Completions API). Prompts are in `lib/prompt.ts`; run files are in `runs/`.

Priority guidance kept for v2, then measured on 20 tickets (see the smoke rows below). |

Re-test below. |
